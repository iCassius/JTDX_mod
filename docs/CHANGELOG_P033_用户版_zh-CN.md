# JTDX P033 用户版更新说明

版本：2.2.159.033
Windows PE 数字版本：2.2.159.33

P033 是一个独立的本机候选包，首次把本轮 CAT 长挂机与首发射修复纳入版本。P032 的既有 ZIP 不含这些修复；本候选没有覆盖任何 P032 文件。

## 本版改动

- CAT 离线状态与同会话 failure 现在按会话代次一次传播；已关闭旧代次的迟到更新不会先污染缓存/UI，也不会关闭新会话。离线期间保留最后有效频率显示并明确标记离线。
- FTX-1 + CAT PTT 的就绪门使用成功且无本次错配的真实 `rig_get_ptt()` 读回；软件 `rig_set_ptt()` 回显不是电台实际 PTT 读回。未消费请求绑定当前 rig 代次和发送意图，上下文改变或请求取消时不启动迟到音频。其他后端沿用原 readback/readiness 行为；未消费请求的取消与上下文保护是共同生命周期保护。
- FTX-1 协议错序失败计数只在至少有一个真实有效读且整轮无 mismatch 时清除；没有成功读取的轮次不会被算作成功。
- AutoSeq 诊断字段以独立字段拼接，避免呼号、空格、百分号、中文等内容改变相邻字段。
- 内部安全 Halt Tx 关闭 Enable Tx 时会保留软件拥有的初始自动 RCQ/RFIN owner，让既有 120 秒停滞判定继续等待完整的新鲜 decode batch、真实 PTT-off 和其他安全条件后再收尾；手动 DX、已进入 QSO 的目标和恢复 ticket 不由该流程清理。
- 保留 P032 本地诊断和故障反馈 ZIP 导出工具。P032 的 AutoSeq 说明和导出指南仍随包提供，导出工具接口没有重设计。

## 使用与验证边界

FTX-1 CAT 就绪判断以真实成功 GET_PTT 读回为来源；PTT 写入后的软件状态边沿不能替代它。其他 backend 的 legacy readiness 不代表真实硬件读回。软件构建、自动化测试、包完整性和合成导出测试不等于用户机器上的 CAT、PTT、音频、发射或硬件在环验收。本候选没有启动 JTDX，没有操作真实 CAT/PTT/TX，也没有进行 HIL 或现场安装。

本说明记录用户可见改动与验证边界；自动化检查、包完整性检查和合成导出测试不等于用户机器上的 CAT、PTT、音频、发射或硬件在环验收。
